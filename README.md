# Number-Ninja-By-Dolly
A simple Number Guessing Game built with Python and Streamlit.

🚀 Features
Interactive web interface
Random number generation
User can enter guesses
Provides feedback on each guess
Displays the result directly in the browser
🛠️ Technologies Used
Python
Streamlit
▶️ Run Locally

Install the required library:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py

The application will open in your browser at:

http://localhost:8501

🌐 Deployment

The project can be deployed using Streamlit Community Cloud so that it can be accessed from phones and other devices through a public web link.
